# Real Force Feedback for ETS2LA

A force feedback (FFB) integration and telemetry plugin for [Euro Truck Simulator 2 Lane Assist](https://github.com/Zia-ullah-khan/Euro-Truck-Simulator-2-Lane-Assist).

## Overview
This module handles direct force feedback calculations, lane centering resistance, and steering rack physics communication between ETS2LA and supported direct drive / FFB steering wheels.

## Stack
- **Runtime:** .NET / C#
- **UI:** Blazor / Razor Components (`Settings.razor`)
- **Integration:** ETS2LA plugin architecture

## Installation
Clone or drop this folder into the ETS2LA plugin directory and enable it in the main dashboard settings.
